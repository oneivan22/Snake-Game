# Змейка (Snake Game)

Классическая игра «Змейка» на Python с использованием Pygame.

## Установка

```bash
pip install pygame
```

## Запуск

```bash
python the_snake.py
```

## Управление

Клавиша  Действие 

↑         Вверх
↓         Вниз 
←         Влево
→         Вправо

## Правила

- Собирай красные яблоки 🍎
- Змейка растёт с каждым яблоком
- Не врезайся в себя!
- При столкновении — игра начинается заново
- Змейка проходит сквозь стены
